# CHIRPS-GEFS rainfall forecasts

**What:** Rainfall forecasts built from the GEFS weather-forecast ensemble, bias-corrected to CHIRPS.
**Link:** https://www.chc.ucsb.edu/data/chirps-gefs
**Licence:** **not confirmed.**
**Status:** page found; whether a historical archive of past forecasts exists for 2015–2025 is **not checked**.

Why it matters: a real early warning must use rain that is *forecast* for the coming week, not rain that was later *observed*. Using observed future rain inflates scores for a tool nobody could run in practice.

## For the capstone
Main model uses only rain up to the prediction date. If a forecast archive exists, add a second experiment with forecast rain and report both side by side; observed future rain may only be shown as a clearly labelled upper bound.
