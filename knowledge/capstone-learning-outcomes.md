# Capstone learning outcomes (LO1–LO7)

The capstone is the main evidence for nearly every course outcome. Every LO should be visible somewhere in the repo or the presentation.

| LO | What the capstone must show | Where it shows up |
|---|---|---|
| LO1 Formulate problems as ML tasks | Decision point, label/target, cost of errors, why supervised/unsupervised/RL | Proposal + Part A of report |
| LO2 End-to-end pipelines | Reproducible data prep, features, model selection, evaluation, basic deployment | Repo + notebooks |
| LO3 Derive core algorithms | **At least two** methods actually used, with the maths shown | Technical report |
| LO4 Evaluate with metrics and validation | Right metrics, diagnostic plots, honest splits/CV, uncertainty | Analysis section + defence |
| LO5 Bias/fairness/ethics mitigations | Datasheet, Model Card, disaggregated metrics, harm analysis, regulatory mapping, one concrete mitigation | Ethics & fairness review |
| LO6 Communicate to both audiences | Report, a user-facing artefact/explainer, clear talk with Q&A | Report + talk + defence |
| LO7 Read research critically | Ground **3–5** methodological choices in the literature | "Related work" + defence |

## For the capstone
LO3: derive logistic regression plus one tree method (split criterion or gradient boosting). LO7: cite Roberts et al. 2017 for temporal/spatial CV, Nearing et al. 2024 for flood forecasting, the Ghana susceptibility studies, and the Groundsource preprint.
