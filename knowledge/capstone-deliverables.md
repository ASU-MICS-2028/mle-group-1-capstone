# Capstone deliverables

**Group deliverables**
1. **GitHub repository** (due Week 14, Fri 11 Dec): README explaining how to reproduce end-to-end; `requirements.txt`; data-loading code; notebooks/scripts; the deployment artefact; a `data/` note saying where the data come from. Never commit private data.
2. **Technical report**: ~8–12 pages, PDF, written like a research paper (sections fixed by the brief).
3. **Ethical & fairness review pack**: Datasheet, Model Card, disaggregated fairness results, proxy analysis, regulatory mapping.
4. **Deployment artefact and presentation slides.**

**Individual deliverables**
5. An **AI-use declaration in every deliverable** you write.
6. A **contribution statement**, ½ page per member, submitted with the repo.

The report draft, ethics pack and artefact are expected complete with the repo in Week 14; the **final report** is submitted in Week 15 with the presentation.

## For the capstone
Groundsource is CC BY 4.0, so it may be redistributable, but raw downloads (667 MB) and Earth Engine exports should be fetched by script, not committed. The `data/` note should give each source's link, licence and access date.

**Lecturer's framing (lecture 9).** The 8–12 page report is there to train paper writing: many people can build models but cannot report them for a technical audience. He does not expect the course work itself to be publishable, but groups can extend it afterwards; past projects were published. He pointed to the GhIE (Ghana Institution of Engineering) conference in March 2027, themed on sustainable urban transport, as a local venue. Contribution statements go in a folder in the repo, one half page per member.
