# Decision log in the repo

In Prosit 2 the README linked to a documentation folder recording every decision the team made, and a learnings folder where each member wrote what they learned. The repo also held written rules so that any newcomer ("an intern") would know how to work in it.

Why it helped:

- Members who did not do a part could catch up by reading the report and the log.
- When writing the report, the reasons for each choice were already written down.
- In a defence, "why did you do X?" has a recorded answer.

A short decision record has: the date, the decision, the options considered, and the reason.

## For the capstone
Keep this habit: one short record per decision (label definition, region-week aggregation, temporal split, threshold choice). The lecturer will drill each member in the defence, and the log is the fastest revision tool.
