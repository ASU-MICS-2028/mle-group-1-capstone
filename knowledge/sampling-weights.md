# Sampling weights

In stratified or cluster designs, units are not all drawn with equal chance. A **sampling weight** says how many population units each sampled unit stands for. Units from under-sampled groups get bigger weights.

- **Weighted** estimates describe the **population**.
- **Unweighted** estimates describe the **sample as drawn**.

Slide example: household net ownership was 70.96% unweighted but 66.77% weighted. Neither is a mistake; they answer different questions. Always say which one you report.

## For the capstone
If we use class weights to handle rare flood weeks, that is also reweighting: say clearly which metrics are weighted.
