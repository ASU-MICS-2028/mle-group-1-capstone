# Contribution statement

An **individual** deliverable: **½ page per member**, submitted **with the code repository** (Week 14, Fri 11 Dec 2026).

It should say what that member owned and did (role, components built, sections written), and — as with every deliverable a student writes — carry an **AI-use declaration**.

It feeds rubric criterion G, "Process & contribution" (10 points). Claims should be checkable against the repo history and the report, so keep commits attributable to the person who did the work.

## For the capstone
Tie each statement to the team-role split and to concrete artefacts (e.g. "built the CHIRPS feature pipeline in `src/...`", "wrote the Model Card").
